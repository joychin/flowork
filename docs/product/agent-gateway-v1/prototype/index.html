为什么人和 AI 走同一条管道？

接入示例 · 10 分钟给 Agent 加上审批门×
① Python SDK（HTTP/MCP 同语义）
import flowork

res = flowork.request(
    action="refund.customer",
    payload={"order_id": "SO-88371", "amount": 86000, "reason": "物流破损"},
    idempotency_key="refund-SO-88371",
)
# → pending_approval: 财务会签 + 店长；agent 在此挂起
result = flowork.wait_for_result(res.request_id)
# → approved / rejected(comment, reason_code) —— 驳回后整改可重提
② MCP 客户端配置（Claude / 任意 MCP 宿主）
{
  "mcpServers": {
    "flowork": {
      "url": "https://flowork.internal.example/mcp",
      "headers": { "Authorization": "Bearer <agent 凭证>" }
    }
  }
}
# 工具面（刻意薄，7 个）：propose / get_status / wait_for_result
#                list_my_approvals / approve / reject / delegate
敏感动作没有这一行就不该被执行 —— 就像没有 OAuth 授权码拿不到 token。
