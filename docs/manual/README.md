# flowork 内核手册

这本手册写给**宿主开发者**——用 Python 把 flowork 引擎嵌进自己系统的人。
它从零开始讲怎么用，概念怎么理解，常见的事怎么做；每一章的代码示例都实际跑通过，
可以直接抄走用。

## 怎么读这本手册

- **第一次接触**：按章节顺序读 01 → 04，跑通第一个流程、看懂核心概念、会画流程图、
  会发布与更新版本，就能上手了；后面各章按需要查。
- **查阅**：每章自成一体，开头有「本章讲什么」；找具体方法签名去 `docs/API.md`（字典），
  找部署运维细节去 `docs/integration.md`。

## 手册的纪律

- **只写现状**：手册描述代码里已经存在的行为，不写规划中的功能。
- **示例可跑**：所有代码示例在写作时实际运行验证过（内存库，秒级）。
- **大白话优先**：概念先解释再用；语义的严格定义在 spec，手册负责让你先理解对。
